# omakasui-devtools

Development tooling for people working across the Omakasui ecosystem.
Everything here is aimed at developers of those projects, not for the end user.

## Commands

```
omakasui theme generate background <themes dir> [output file]   Generate background.png wallpapers
omakasui theme generate bootloader <themes dir> [output file]   Generate GRUB bootloader backgrounds
omakasui theme generate logo <themes dir> <logo.png>             Generate themed unlock.png logos
omakasui theme generate preview <themes dir>                     Generate preview-unlock.png previews
omakasui theme format previews <themes dir>                      Resize/optimize existing preview images
```

Run `omakasui commands --all` for the full list, or `omakasui <command> --help` for details.
